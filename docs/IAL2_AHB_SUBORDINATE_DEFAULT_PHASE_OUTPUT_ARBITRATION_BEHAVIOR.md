Task-tree owner:
`IAL2-AHB-SUBORDINATE-DEFAULT-PHASE-OUTPUT-ARBITRATION.3`

## Outcome

only the output ownership each phase requires. The repair removes exactly five
redundant writes in
`perl/FSM/IAL2/ProtocolIntent/AhbSubordinate.pm`; generic selector analysis and

Base, byte-lane, SEQ, HBURST/SEQ, and BUSY-park generated endpoints are

syntax, ports, signal names, values, timing, reports, support accounting,
review artifacts, normalized semantic JSON, read-only MCP behavior, protocols,

## Exact Generated IAL1 Shape

The three phase rules now own:

```text
ahb_phase_capture:
  phase-bank storage
  HREADYOUT <- 0

ahb_phase_hold:
  HREADYOUT <- 0

ahb_error_retire:
  HREADYOUT <- 1
  HRESP     <- OKAY
```

The removed writes are capture/hold `HRESP <- OKAY`, capture/hold
`HRDATA <- 0`, and retirement `HRDATA <- 0`. No other source line changes.

Transaction idle supplies OKAY and zero data during capture and hold. Existing
different-value priority suppression keeps idle `HREADYOUT <- 1` out while
capture or hold owns not-ready. On final ERROR plus same-edge capture,
retirement supplies OKAY, capture supplies not-ready, and HRDATA remains zero
from the immediately preceding first/final ERROR drives. Enter-data, read,
write, first ERROR, and final ERROR output families are unchanged.
